Implement the PDF certificate-generation service using ReportLab.

Requirements:
1. Create one predefined, professional landscape certificate template.
2. Include organization/event heading, certificate title, recipient name, course name, event date, and certificate ID.
3. Use readable typography, spacing, borders, and a polished but restrained design.
4. Generate exactly one PDF per valid recipient.
5. Save PDFs under generated_certificates/<job_id>/<certificate_id>.pdf.
6. Use UUID-based filenames, never user-supplied names as filesystem paths.
7. Create directories safely and handle missing directories.
8. Ensure each PDF is a valid, readable PDF and that recipient-specific information appears in its document text.
9. Keep template rendering separate from API routes and database logic.
10. Raise meaningful exceptions when PDF generation fails; do not silently create an empty or corrupt file.

Implement a service function with a clear interface, such as generate_certificate(certificate_data, output_path).

Add unit tests for successful PDF generation, output-file existence, valid PDF structure, and recipient-specific content.

Do not generate PDFs for invalid recipient records. Do not build a template editor or multiple template designs.

Run the PDF tests and report the results.
