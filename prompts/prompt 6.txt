Audit and complete the automated tests for the Bulk Certificate Generator against the assignment requirements.

Use pytest and FastAPI TestClient or HTTPX. Use an isolated SQLite test database where compatible, or a separate disposable PostgreSQL test database. Never run tests against production or an existing personal database.

Required test coverage:

1. Creating a generation job with multiple recipients.
2. Rejecting malformed top-level input and enforcing the batch-size limit.
3. Recording invalid individual recipients without rejecting valid recipients.
4. Generating a valid PDF with the correct recipient-specific information.
5. Correct job status, total count, success count, failure count, and progress.
6. Simulating one certificate-generation failure while confirming subsequent valid recipients still succeed.
7. Retrieving a successful PDF through the download endpoint.
8. Returning appropriate errors for unknown job and certificate IDs.
9. Handling jobs where every recipient is invalid.
10. Ensuring failed or pending certificates cannot be downloaded as successful PDFs.

Mock the PDF-generation service to simulate failures deterministically. Do not rely on random failures or real external services.

Avoid brittle tests that depend on exact timestamps or filesystem ordering. Ensure test data and generated files are cleaned up.

Run the full test suite and fix implementation defects rather than weakening assertions. Report the number of passed, failed, and skipped tests. Do not claim tests passed unless you actually ran them.
